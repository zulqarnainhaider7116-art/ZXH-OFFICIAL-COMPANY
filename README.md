# ZXH Official Company

Premium digital headquarters for **ZXH Official Company** — Founder: Zulqarnain X Haider.

## What this is

An immersive company-room website: entrance, founder office, work desk, services wall, project showroom, technology board, reception.

## Run

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm run preview
```

The app is a standard Vite + TanStack Start project and deploys to Vercel / similar hosts from the production build.

## Notes

- Theme (light / dark room lighting) is stored locally in the browser.
- Install prompt appears after a few seconds on supported browsers.
- Social and WhatsApp links are the official ZXH destinations.
